# 录放音配置

> 适用版本：NSBC/2.7+（含 ringback app、拨号规则级录音格式、ffmpeg 后处理转码）
>
> 涉及组件：`nsbcd`（录音写入 / 放音引擎 / dialplan app）、`nsbc-web`（配置管理 / 拨号规则编辑 / 录音列表与播放）、`ffmpeg`（格式转码）

---

## 一、总览

```
拨号规则 (dialplan rule)
   │
   ├── 放音类 app（app_chain）
   │     ├── ringback        回铃音：循环放音，B 腿接通瞬间自动停
   │     ├── playback        提示音：播完 EOF 自然结束，不可打断
   │     ├── post_playback   接通后放音（相位标记）
   │     └── endless_playback  保持音乐：无限循环，uuid_break 打断
   │
   └── record app（录音）
         ├── data = "start"               用全局格式录音
         └── data = "start format=mp4"    本条规则强制 mp4（覆盖全局）
                │
                ▼
         recorder（C 端，实时写 WAV PCM）
                │ 通话结束 / record stop
                ▼
         ffmpeg 后处理（格式 != wav 时）
                │
                ▼
         /var/lib/nsbc/recordings/{date}/{caller}-{callee}-{callid}.{ext}
                │
                ▼
         Web 录音列表 → <audio> 在线播放 → 下载
```

**格式优先级**：`record app 的 format=` （单条规则） `>` `recording.format`（YAML 全局） `>` `wav`（兜底默认）

## 二、录音

### 2.1 全局配置（nsbc.yaml）

```yaml
recording:
  path: /var/lib/nsbc/recordings   # 录音根目录（Web 下载也从这个目录读）
  format: wav                      # wav | mp3 | opus | mp4（全局默认格式）
  mode: mixed                      # single | mixed | separate
```

| 配置项 | 说明 |
|--------|------|
| `recording.path` | 录音文件根目录；Web 端读同一份 YAML，下载路由以此为根做目录穿越防护 |
| `recording.format` | 全局录音格式，**支持热更新**（`CGF_HOT`），改完无需重启 |
| `recording.mode` | `mixed` 双路混为单声道；`separate` 双声道（L=A 路，R=B 路）；`single` 单路 |

### 2.2 格式说明

| format | 文件后缀 | ffmpeg 参数 | 依赖 | 适用场景 |
|--------|----------|-------------|------|----------|
| `wav` | `.wav` | （原生 PCM，不走 ffmpeg） | 无 | 默认；零依赖；体积最大 |
| `mp3` | `.mp3` | `-c:a libmp3lame -b:a 128k` | ffmpeg + libmp3lame | 通用播放器兼容、对外分发 |
| `opus` | `.opus` | `-c:a libopus -b:a 64k` | ffmpeg + libopus | 省存储（约为 wav 的 1/10），专利无关 |
| `mp4` | `.mp4` | `-c:a aac -b:a 128k -movflags +faststart` | ffmpeg（aac 内置） | 浏览器 `<audio>`/`<video>` 直接播放；**当前仅 AAC 音频轨**，视频轨见 2.6 |

> **mp4 视频说明**：当前录音管线只有音频输入通道（`rec_feed` PCM / `rec_feed_raw` G711），
> mp4 输出为「单 AAC 音频轨的合法 mp4」。WebRTC/视频通话的**视频轨录制**需要后续为
> media_bridge 增加视频帧 hook（`rec_feed_video`），规划中。

### 2.3 热切换格式（不用重启 nsbcd）

**方式 A：Web Config Hot-Editor（推荐）**

1. Web 管理界面 → 系统设置 → Config Hot-Editor
2. 找到 `recording.format` 行 → 点 Edit
3. 下拉选择目标格式（wav / mp3 / opus / mp4，带中文说明）→ Validate → Hot-Set
4. **下一次通话**的录音即用新格式

**方式 B：改 YAML + SIGHUP**

```bash
vim /etc/nsbc/nsbc.yaml      # recording.format: mp4
kill -HUP $(pgrep nsbcd)     # 触发 YAML reload，无需重启
```

两种方式等效；生效粒度都是「下一次录音」，已在录的通话不受影响。

### 2.4 拨号规则级录音格式（per-rule）

在拨号规则的 `app_chain` 里用 `record` app，`data` 支持 `format=` 参数：

```json
[
  {"app": "record", "data": "start format=mp4"},
  {"app": "bridge",  "data": "user/1000"},
  {"app": "record", "data": "stop format=mp4"}
]
```

- `format=` 合法值：`wav` / `mp3` / `opus` / `mp4`，非法值告警并忽略（回退全局）
- 只影响**本条规则命中的通话**，不影响其他规则和全局默认
- 常见用法：普通分机通话录 `opus` 省空间，投诉热线单独一条规则录 `mp3` 便于对外提供

**Web 配置入口**：拨号规则编辑 → app_chain 结构化编辑器 → 添加 `record` app，
data 输入框 placeholder 已提示 `start format=mp4 (or stop / start format=mp3|opus|wav)`。

### 2.5 录音文件命名与存储

默认路径模板：`{date}/{caller}-{callee}-{callid}.{ext}`

| 变量 | 含义 |
|------|------|
| `{date}` | 通话日期 `yyyymmdd`（按天分目录） |
| `{caller}` / `{callee}` | 主 / 被叫号码（缺失时 `anon` / `unknown`） |
| `{callid}` | SIP Call-ID |
| `{ext}` | 实际输出后缀（wav/mp3/opus/mp4） |

双路录音（`separate` 模式或分腿录制）通话结束时自动合并为 stereo mix 并删除中间单声道文件，再进入 ffmpeg 转码。

### 2.6 ffmpeg 转码行为与故障兜底

- 转码发生在**录音停止时**（record stop 或通话结束），`fork + execvp("ffmpeg")` 同步等待完成
- 转码成功：删除中间 WAV，日志 `app_record CONVERT callid=xxx → .mp4`
- 转码失败（ffmpeg 未安装 / 编码器缺失 / 磁盘满）：**保留 WAV 兜底**，日志 `WARN ... CONVERT failed ... keeping WAV`
- 因此生产环境**必须安装 ffmpeg**：

```bash
# Ubuntu / Debian
apt-get update && apt-get install -y ffmpeg
# 验证编码器
ffmpeg -encoders 2>/dev/null | grep -E "libmp3lame|libopus| aac "
```

### 2.7 Web 录音列表 / 播放 / 下载

- `GET /api/v1/recordings` — 分页列表（按主被叫 / 时间过滤），数据来自 CDR 的 `rec_path`
- `GET /recordings/*path` — 文件下载（HTML5 `<audio>` 在线播放走此路由，支持 Range）
- 下载白名单后缀：`.wav .g711a .g711u .pcm .raw .mp3 .opus .mp4`（含新格式）
- Content-Type 映射：wav→`audio/wav`，mp3→`audio/mpeg`，opus→`audio/ogg`，mp4→`audio/mp4`，其余 `application/octet-stream`

## 三、放音

### 3.1 四种放音 app 的语义对比

| app | 播放方式 | 停止条件 | chain 是否阻塞 | 典型场景 |
|-----|----------|----------|----------------|----------|
| `ringback` | **循环** | **B 腿接通（200 OK）瞬间自动停** | 非阻塞，立即执行下一 app | 转分机时给主叫放回铃音 |
| `playback` | 单次 | 播完 EOF 自然结束 | 非阻塞 | 放提示音 / 欢迎语 |
| `post_playback` | 单次 | 播完 EOF | 非阻塞（接通后相位标记） | 接通后播放置顶公告 |
| `endless_playback` | 无限循环 | `uuid_break` 打断 | 非阻塞 | 保持音乐（MoH） |

**核心区别**：
- `ringback` 是唯一被「接通」事件自动打断的放音 —— 专门为「转分机的同时放回铃音」设计，
  可以配在 `bridge` / `transfer` **之前**；
- `playback` 语义是「必须播完」，不受接通影响（提示音场景下接通前早已播完）；
- 接通时若仍有残留放音（如配置了 ringback 但呼叫失败转语音信箱），也会被切断，属正确兜底。

### 3.2 ringback 配置示例

拨号规则 `app_chain`（Web 拨号规则编辑器 → 结构化 app 编辑器 → Early Media 组第一位）：

```json
[
  {"app": "pre_answer"},
  {"app": "ringback", "data": "/var/lib/nsbc/sounds/ringback.wav"},
  {"app": "bridge",   "data": "user/1000"}
]
```

效果：入呼 → 183/pre-answer 建立早期媒体 → A 腿循环听回铃音 → 分机 1000 振铃 →
1000 接听（200 OK 到达 nsbcd 的瞬间）→ 回铃音自动切断 → 双方正常通话。

> 实现位置：`b2bua.c` 三个 `LEG_CONFIRMED` 点（B 腿 200 OK / originate A 腿 200 OK /
> A 腿 ACK）统一调 `pb_stop_if_playing(c)`，任一接通路径都会停掉 ringback。

### 3.3 放音文件要求

- 格式：WAV PCM（8kHz / 16bit；与 pb 引擎时钟一致）
- 路径：**推荐绝对路径**；相对路径按 `nsbcd` 进程工作目录解析，不建议生产使用
- 同一通话同时只有一个放音会话：新放音启动前自动停止旧放音

### 3.4 提示音资产建议

```
/var/lib/nsbc/sounds/
  ├── ringback.wav      回铃音（循环体，建议 2~4 秒无缝循环）
  ├── welcome.wav       欢迎语
  ├── hold_music.wav    保持音乐
  └── busy_tone.wav     示忙音
```

放音文件管理暂无 Web 上传界面，由运维直接放置到服务器目录。

## 四、部署清单

```bash
# 1. 安装 ffmpeg（mp3/opus/mp4 必需；纯 wav 可跳过）
apt-get install -y ffmpeg

# 2. 编译并部署 nsbcd（含 recorder / playback_engine / app_registry / b2bua 改动）
# 3. 编译并部署 nsbc-web（含下载白名单 / Content-Type / app-chain 编辑器改动）
# 4. 准备放音资产
mkdir -p /var/lib/nsbc/sounds
#    放入 ringback.wav / welcome.wav ...

# 5. 配置（可选，默认 wav 即可工作）
#    Web → 系统设置 → Config Hot-Editor → recording.format
#    或 vim nsbc.yaml + kill -HUP $(pgrep nsbcd)
```

## 五、验证与排查

| 现象 / 检查点 | 命令 / 日志关键词 | 预期 |
|---------------|-------------------|------|
| 录音格式生效 | `tail -f logs/nsbcd.log \| grep -E "CONVERT\|MERGE\|STOP"` | `app_record CONVERT callid=xxx → .mp4` |
| ffmpeg 缺失 | 同上 | `WARN ... CONVERT failed ... keeping WAV`（兜底保留 WAV） |
| ringback 接通停 | 通话测试 | 分机接听瞬间回铃音切断，无残留 |
| 录音下载 403 | Web 录音页点播放 | 白名单内后缀正常播放；检查文件是否在 `recording.path` 下 |
| 热切换不生效 | `kill -HUP $(pgrep nsbcd)` 后再测一通 | 新通话用新格式 |
