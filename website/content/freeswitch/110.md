# FreeSwitch的a,b leg同时呼叫


		<a href="110.html"><h1>FreeSwitch的a,b leg同时呼叫</h1></a>
                <br/><b>                <p>今天遇到一网友说，他在使用FreeSwitch做外呼时，发现先呼a leg后再呼b leg时效率很差，所以想 a,b leg同时呼叫，其实送个假信号就可以了，如：</p>
<pre><code>originate {return_ring_ready=true}sofia/gateway/nwaytest/18621575908 &amp;bridge(user/8001)
</code></pre>
<p>这里与众不同的是什么呢？{return_ring_ready=true}这个通道变量，就是在送到a时，马上让系统认为a leg准备好了，你可以下一步了。</p> <br/><hr/>上海老李，QQ:1354608370，FreeSWITCH  QQ群：
