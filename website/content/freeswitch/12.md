# FreeSWITCH与线路采用密码验证`n`n		FreeSWITCH与线路采用密码验证
                                在通常情况下，FreeSWITCH需要通过落地对接后，和第三方的线路或设备进行互联互通，然后把话务输出出去，那么怎么办呢？在FreeSWITCH中，与外部对接的接口叫Gateway（中文称之网关）。
以下就是一个配置的网关的例子：
在$FS_PATH/conf/sip_profiles/external/下建一个文件如nway.xml
```markdown
&lt; include&gt;

    &lt;gateway name=&#34;nway&#34;&gt;

        &lt;param name=&#34;username&#34; value=&#34;51531234&#34;/&gt;

        &lt;param name=&#34;password&#34; value=&#34;23332ddefrr&#34;/&gt;

        &lt;param name=&#34;realm&#34; value=&#34;220.196.xx.xxx&#34;/&gt;

        &lt;param name=&#34;proxy&#34; value=&#34;220.196.xx.xxx&#34;/&gt;

        &lt;param name=&#34;register&#34; value=&#34;true&#34;/&gt;

    &lt;/gateway&gt;

&lt; /include&gt;

```
然后freeswitch -stop &amp;&amp; freeswitch -nc 或者运行fs_cli后：
sofia profile external rescan reloadxml
