<p>Configure FreeSWITCH</p>
<p>SIP.js has been tested with FreeSWITCH 1.5.14 without any modification to the source code of SIP.js or FreeSWITCH. Later versions of FreeSWITCH will require similar configuration.</p>
<p>System Setup</p>
<p>FreeSWITCH and SIP.js were tested using the following setup:</p>
<p>CentOS 6.6 minimal (x86_64)</p>
<p>FreeSWITCH 1.5.14</p>
<p>A public IP address to avoid NAT scenarios on the server side.
Required Packages</p>
<p>Install the following dependencies:
<code>git
autoconf
automake
libtool
gcc-c++
libuuid-devel
zlib-devel
libjpeg-devel
ncurses-devel
openssl-devel</code>
Using YUM, all dependencies can be installed with:</p>
<p>yum install git autoconf automake libtool gcc-c++ libuuid-devel zlib-devel libjpeg-devel ncurses-devel openssl-devel</p>
<p>Install FreeSWITCH</p>
<p>FreeSWITCH recommends using the latest version of FreeSWITCH from the FreeSWITCH git repo. This example uses FreeSWITCH tag v1.5.14.</p>
<p>```</p>
<pre><code>cd /usr/local/src/

git clone https://freeswitch.org/stash/scm/fs/freeswitch.git

cd /usr/local/src/freeswitch

git checkout v1.5.14

./bootstrap.sh

./configure

make (This may take a few minutes.)

make install
</code></pre>
<p>```</p>
<p>Configure FreeSWITCH</p>
<p>The default configuration files for FreeSWITCH are located in /usr/local/freeswitch/conf.</p>
<p>Start by editing the internal SIP profile sip_profiles/internal.xml. Uncomment the line <param name="ws-binding" value=":5066"/> to allow web sockets to talk to FreeSWITCH. No other configuration changes are necessary to make FreeSWITCH work with WebRTC.</p>
<pre><code>```
&lt;!--internal.xml--&gt;

&lt;!-- Uncomment the following: --&gt;

&lt;param name=&#34;ws-binding&#34;  value=&#34;:5066&#34;/&gt; 
```
</code></pre>
<p>If you’d like to enable video as well as audio, adjust FreeSWITCH’s codec preferences to include VP8.</p>
<pre><code>&lt;!--vars.xml--&gt;

&lt;X-PRE-PROCESS cmd=&#34;set&#34; data=&#34;global_codec_prefs=PCMU,PCMA,VP8&#34;&gt;

&lt;X-PRE-PROCESS cmd=&#34;set&#34; data=&#34;outbound_codec_prefs=PCMU,PCMA,VP8&#34;&gt;
```
</code></pre>
<p>Start FreeSWITCH: /usr/local/freeswitch/bin/freeswitch.</p>
<p>Configure SIP.js</p>
<p>SIP.js works with FreeSWITCH without any special configuration parameters. The following UA is configured to connect to a default FreeSWITCH configuration. Replace 127.0.0.1 with the IP address of your FreeSWITCH server.</p>
<pre><code>```
var config = {

  // Replace this IP address with your FreeSWITCH IP address

  uri: &#39;1000@127.0.0.1&#39;,

  // Replace this IP address with your FreeSWITCH IP address

  // and replace the port with your FreeSWITCH port

  ws_servers: &#39;ws://127.0.0.1:5066&#39;,

  // FreeSWITCH Default Username

  authorizationUser: &#39;1000&#39;,

  // FreeSWITCH Default Password

  password: &#39;1234&#39;

};

var ua = new SIP.UA(config);
```
</code></pre>
<p>Troubleshooting</p>
<p>It is known that SIP.js and FreeSWITCH might not interop well if you have the following option enabled on FreeSWITCH:</p>
<pre><code>```
&lt;variable name=&#34;sip-force-contact&#34; value=&#34;NDLB-connectile-dysfunction&#34;/&gt;
```
</code></pre>
<p>Firefox 34+ requires SIP.js 0.6.4 or later to interop with FreeSWITCH or Asterisk.</p>
