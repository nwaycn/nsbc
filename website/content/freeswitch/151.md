# go Lang 的grpc的试验


		<a href="151.html"><h1>go Lang 的grpc的试验</h1></a>
                <br/><b>                <p>QQ群：protobuf-gRPC学习群   298735073 </p>
<p>今天遇到一个网友说go lang 的grpc怎么用？按网上的总有问题，好吧，我就再试试go lang的grpc，毕竟有段时间不用它了！</p>
<ol>
<li>首先就是安装 go lang ,这个就不再另行说了，至少说go lang的源码打包等很方便，比如我们要装个grpc,则<pre><code>go get google.golang.org/grpc
</code></pre>
</li>
</ol>
<p>最好还是先手工把c++的protobuf 3.x的源码编译下，我是win 10 64位，采用cmake生成sln后，由vs2010就编译好了，然后把生成的含protoc.exe的路径添加到path中，然后：</p>
<pre><code>    go get -u github.com/golang/protobuf/{proto,protoc-gen-go}
</code></pre>
<p>于是乎就可以生成grpc的东东了，我们的proto文件如下，helloworld.proto,这个文件是放在了%GOPATH%\src\grpc\xcl下：</p>
<p>```</p>
<pre><code>syntax = &#34;proto3&#34;;

package xcl;



enum UserStatus {  
    OFFLINE = 0;  
    ONLINE = 1;  
 }

message UserInfo {  
  int32 id = 1;   
  string name = 2;   
  UserStatus status = 3 ;  
}

message UserID {  
  int32 id = 1;   
}

message funcResponse {      
   string reply = 1;  
}

service UserService {  
  rpc Login(UserInfo) returns (funcResponse){};  
  rpc logout(UserID) returns (funcResponse){};  
}
</code></pre>
<p>```</p>
<p>进入cmd后，</p>
<pre><code>         protoc --go_out=plugins=grpc:. helloworld.proto
</code></pre>
<p>就会有helloworld.pb.go文件生成</p>
<ol>
<li>编写server.go</li>
</ol>
<p>```</p>
<pre><code>package main

import (
    pb &#34;grpc/xcl&#34;

    &#34;log&#34;
    &#34;net&#34;
    &#34;os&#34;

    &#34;golang.org/x/net/context&#34;
    &#34;google.golang.org/grpc&#34;
)

func main() {

    log.SetOutput(os.Stdout)
    lis, err := net.Listen(&#34;tcp&#34;, port)
    if err != nil {
        log.Fatalf(&#34;failed to listen: %v&#34;, err)
    }
    s := grpc.NewServer()
    pb.RegisterUserServiceServer(s, &amp;server{})

    log.Println(&#34;Server......&#34;)
    s.Serve(lis)

}

const (
    port = &#34;:50051&#34;
)

type server struct{}

func (s *server) Login(ctx context.Context, usr *pb.UserInfo) (*pb.FuncResponse, error) {
    log.Println(&#34;Server...... Login() UserInfo:&#34;, usr)

    usr.Id = 100
    strId := &#34;100&#34; //strconv.Itoa(usr.Id)

    return &amp;pb.FuncResponse{Reply: strId}, nil

}

func (s *server) Logout(ctx context.Context, uid *pb.UserID) (*pb.FuncResponse, error) {
    log.Println(&#34;Server...... Logout() UserID:&#34;, uid)
    return &amp;pb.FuncResponse{Reply: &#34;Logout Successed.&#34;}, nil
}
</code></pre>
<p>```</p>
<ol>
<li>编写client.go</li>
</ol>
<p>```</p>
<pre><code>package main

import (
    &#34;log&#34;
    &#34;os&#34;
    &#34;strconv&#34;

    pb &#34;grpc/xcl&#34;

    &#34;golang.org/x/net/context&#34;
    &#34;google.golang.org/grpc&#34;
)

const (
    address = &#34;127.0.0.1:50051&#34;
)

func main() {
    log.SetOutput(os.Stdout)

    conn, err := grpc.Dial(address, grpc.WithInsecure())
    if err != nil {
        log.Fatalf(&#34;did not connect: %v&#34;, err)
    }
    defer conn.Close()
    c := pb.NewUserServiceClient(conn)

    var status pb.UserStatus
    status = pb.UserStatus_ONLINE

    userInfo := &amp;pb.UserInfo{
        //Id:     10,         //proto.Int32(10),
        Name:   &#34;XCL-gRPC&#34;, //proto.String(&#34;XCL-gRPC&#34;),
        Status: status,
    }

    r, err := c.Login(context.Background(), userInfo)
    if err != nil {
        log.Fatalf(&#34;登录失败!  %v&#34;, err)
    }
    log.Println(&#34;Login():&#34;, r)

    uid, err := strconv.ParseInt(r.Reply, 10, 32)
    if err != nil {
        log.Fatalf(&#34;非数字  %v&#34;, err)
    }

    userID := &amp;pb.UserID{int32(uid)}
    out, err := c.Logout(context.Background(), userID)
    log.Println(&#34;Logout():&#34;, out)
}
</code></pre>
<p>```</p>
<p>这两个可以是任意处置，我是放在了 %GOPATH%\src\grpc</p>
<ol>
<li>启动两个cmd命令行下，且都cd 到了server.go,client.go的文件路径下</li>
</ol>
<p>cmd a:    go build server.go  生成server.exe</p>
<p>cmd b:    go build client.go   生成client.exe</p>
<p>再分别运行，那么就可以看到</p>
<p>server.exe一直在监听，client.exe出现了</p>
<p>```</p>
<pre><code>2017/01/20 21:09:46 Login(): reply:&#34;100&#34;
2017/01/20 21:09:46 Logout(): reply:&#34;Logout Successed.&#34;
</code></pre>
<p>```</p>
<p>特别要注意，client.go 下 dial 时，要指定 conn, err := grpc.Dial(address, grpc.WithInsecure())，这也是之前的小兄弟遇到的问题，会异常为： </p>
<pre><code>     did not connect: grpc: no transport security set (use grpc.WithInsecure() explicitly or set credentials)
