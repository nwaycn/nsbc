# FreeSwitch和1号及7号的关系


		<a href="162.html"><h1>FreeSwitch和1号及7号的关系</h1></a>
                <br/><b>                <p>最近，有人问我，FS中如何配1号和7号信令，这个要分两个层面看了。</p>
<ol>
<li>
<p>FS理论只对接网关或软交换等，它不会去对pri等进行转换后，再去以sip或h323等送出去，这些工作是由网关或对接的软交换等系统完成的。</p>
</li>
<li>
<p>即使FS中使用sangoma卡，其实也是由sangoma卡完成相应的1号或7号信令处理工作，FS只管好自己的这一块工作。</p>
</li>
