<p>在其它版本的linux中，编译mod_av的话，可以使用官方的libav包，不过都不如debian 8版本来得快，如centos 6配了epel的情况下，操作如下:
先装依赖库：</p>
<pre><code>yum install -y git subversion autoconf automake libtool gcc-c++ ncurses-devel make

yum -y install expat-devel openssl-devel libtiff-devel libX11-devel unixODBC-devel libssl-devel python-devel 
yum -y install zlib-devel libzrtpcpp-devel alsa-lib-devel libogg-devel libvorbis-devel perl-libs gdbm-devel 
yum -y install libdb-devel uuid-devel @development-tools  patch

yum -y install ldns-devel libidn-devel unbound-devel
yum -y install libjpeg-devel
yum -y install pcre-devel
yum -y install speex-devel yasm nasm


wget -c http://files.freeswitch.org/downloads/libs/libav-12.tar.bz2  
tar -jxvf libav-12.tar.bz2
./configure --disable-static --enable-shared --enable-pic
 make CXXFLAGS=&#34;-fPIC&#34;
make install
</code></pre>
<p>参上有关centos下的安装依赖，出现问题解决问题，只要不是缺心眼，总能安装成功的。</p>
<p>Debian 8 下编译有mod_av的FreeSWITCH 1.7版 </p>
<ol>
<li>安装 Debian 8</li>
</ol>
<p><strong>切记，切记：一定要 64位的debian，而不是32位或别的系统</strong></p>
<ol>
<li>通过图形管理界面更改ip地址为静态的或通过命令更改</li>
</ol>
<p>前提，加载安装盘，先装个vim，在debian下，vi我认为不好用</p>
<p>修改 /etc/network/interfaces ，如：</p>
<pre><code>auto eth0 #设置设备名称

iface eth0 inet static #设置接口类型，static为静态ip，或者为dhcp

address 192.168.1.1 #接口地址

netmask 255.255.255.0 #掩码

gateway 192.168.1.254 #网关
</code></pre>
<p>为了让配置生效，运行<code>/etc/init.d/networking restart</code></p>
<ol>
<li>配置debian源</li>
</ol>
<p>vim /etc/apt/sources.list</p>
<p>变成以下内容：</p>
<pre><code># deb cdrom:[Debian GNU/Linux 8.1.0 _Jessie_ - Official amd64 DVD Binary-1 20150606-14:19]/ jessie contrib main

#deb cdrom:[Debian GNU/Linux 8.1.0 _Jessie_ - Official amd64 DVD Binary-1 20150606-14:19]/ jessie contrib main

#deb http://security.debian.org/ jessie/updates main contrib
#deb-src http://security.debian.org/ jessie/updates main contrib

deb http://mirrors.163.com/debian-security jessie/updates main contrib non-free

deb http://security.debian.org jessie/updates main contrib non-free
#以上禁掉cdrom和deb原生源，改为163的，加快速度
# jessie-updates, previously known as &#39;volatile&#39;

# for your mirror of choice.
#

# deb-src http://ftp.debian.org/debian/ jessie-updates main contrib
</code></pre>

<pre><code>wget -O - https://files.freeswitch.org/repo/deb/debian/freeswitch_archive_g0.pub | apt-key add -

echo &#34;deb http://files.freeswitch.org/repo/deb/freeswitch-1.6/ jessie main&#34; &gt; /etc/apt/sources.list.d/freeswitch.list
echo &#34;deb http://files.freeswitch.org/repo/deb/debian-unstable/ jessie main&#34; &gt;&gt; /etc/apt/sources.list.d/freeswitch.list
apt-get update
apt-get install -y --force-yes freeswitch-video-deps-most

./configure

# Install audio files:
make cd-sounds-install cd-moh-install

# To update an installed build:
cd /usr/src/freeswitch

</code></pre>
<p>a. 添加freeswitch的源</p>
<p><code>echo &#34;deb http://files.freeswitch.org/repo/deb/debian/ jessie main&#34; &gt; /etc/apt/sources.list.d/99FreeSWITCH.test.list</code></p>
<p><code>wget -O - http://files.freeswitch.org/repo/deb/debian/key.gpg |apt-key add -</code></p>
<p><code>apt-get update</code></p>
<p>a2. 针对fs1.6最新版,直接安装</p>
<pre><code>wget -O - https://files.freeswitch.org/repo/deb/debian/freeswitch_archive_g0.pub | apt-key add -

echo &#34;deb http://files.freeswitch.org/repo/deb/freeswitch-1.6/ jessie main&#34; &gt; /etc/apt/sources.list.d/freeswitch.list

apt-get update &amp;&amp; apt-get install -y freeswitch-meta-all
</code></pre>
<p>a3. 针对2016年2月后master或v1.6版本,a 和b不需要执行，先执行a,b，反而会造成安装源包的依赖异常</p>
<pre><code>wget -O - https://files.freeswitch.org/repo/deb/debian/freeswitch_archive_g0.pub | apt-key add -

echo &#34;deb http://files.freeswitch.org/repo/deb/freeswitch-1.6/ jessie main&#34; &gt; /etc/apt/sources.list.d/freeswitch.list

apt-get update

apt-get install -y --force-yes freeswitch-video-deps-most
</code></pre>
<p>b. 安装依赖</p>
<p><code>DEBIAN_FRONTEND=none APT_LISTCHANGES_FRONTEND=none apt-get install -y --force-yes freeswitch-video-deps-most</code></p>
<p>c. git FreeSWITCH的源码</p>
<pre><code>git config --global pull.rebase true
git clone https://freeswitch.org/stash/scm/fs/freeswitch.git freeswitch.git
cd freeswitch.git
./bootstrap.sh -j
./configure -C
</code></pre>
<p>d. 开启mod_av模块</p>
<p><code>perl -i -pe &#39;s/#applications\/mod_av/applications\/mod_av/g&#39; modules.conf</code></p>
<p>e. 编译并install</p>
<pre><code>make
make install
make cd-sounds-install 
make cd-moh-install 
make samples
</code></pre>
<p>f. 修改内核参数</p>
<p><code>vim /etc/sysctl.d/vid.conf</code></p>
<pre><code>net.core.rmem_max = 16777216 
net.core.wmem_max = 16777216 
kernel.core_pattern = core.%p
</code></pre>
<p>系统调用使之生效 </p>
<pre><code>sysctl -w net.core.rmem_max=16777216 
sysctl -w net.core.wmem_max=16777216 
sysctl -w kernel.core_pattern=core.%p
</code></pre>
<p>g. 将mod_av加载了，fs_cli中load mod_av或autoload_configs/modules.conf.xml 中加一行， 
并在conf/vars.xml中的编码部分添加H264 </p>
<p>h. 添加freeswitch和fs_cli的软链接后，运行freeswitch后，拨3500后试试吧 </p>
