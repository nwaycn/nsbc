# 如何在FreeSwitch中回拨模式下，支持a路自动接听且a路能听到实际的b路的真实回铃


		<a href="172.html"><h1>如何在FreeSwitch中回拨模式下，支持a路自动接听且a路能听到实际的b路的真实回铃</h1></a>
                <br/><b>                <p>首先在这里，有一个前提，我们的a路的终端支持自动接听(auto_answer)才可以这么玩，否则只能老老实实等振铃后，手工接听。</p>
<pre><code>originate {auto_answer=true}sofia/external/18621575908@1.1.1.1 &amp;bridge({instant_ringback=true}sofia/external/13671947488@1.1.1.1)
</code></pre>
<p>这里有两个参数：</p>
<p>auto_answer对于支持自动应答的终端才有效，典型的eyebeam中有个AA小按钮。</p>
<p>instant_ringback 为true时，则会使用等到的b 路的实际ringback</p> <br/><hr/>上海老李，QQ:1354608370，FreeSWITCH  QQ群：
