# 宁卫AI智能交互系统平台-“电话机器人”

## 宁卫AI智能对话系统发布了-“电话机器人”

作为技术人，我们其实挺纠结的，叫电话机器人，装13又怕被雷劈，太老实的话，又实在没有什么吸引力。为什么呢？机器人应是具有相对一定智能我们才能称之为人，但可惜，当下我们的人工智能如果要用在电话应用上，还是不太现实，同时人工智能也不如我们想象中的那么“智能”。

一、 宁卫AI智能对话系统的作用

由于之前我们上海宁卫出了一系列的通信应用的中间件，但是对于终端用户来说，还是有不少的门槛，特别是要对业务比较熟的开发人员，这对很多非技术类企业来说，就是噩梦。对不少企业来说是花钱也找不到合适的开发人员。故而我们把fsgui、nway_power等一起打包成为了一个完整的平台，以便客户能经过简单的培训就可以使用，而不是还要自己有研发开发。

二、宁卫AI智能对话系统的特点

```
`批量号码导入
自定义话术
对话上下文跟踪
每个项目都可以限制并发量
支持自建，终端用户可以保证自己的数据安全
支持动态变量
支持实时打断
支持TTS和录音混插
支持呼入与呼出

```
