# 使用postgresql作为FreeSWITCH内核数据库


		<a href="20.html"><h1>使用postgresql作为FreeSWITCH内核数据库</h1></a>
                <br/><b>                <p>来自于： <a href="https://wiki.freeswitch.org/wiki/PostgreSQL_in_the_core" title="https://wiki.freeswitch.org/wiki/PostgreSQL_in_the_core">https://wiki.freeswitch.org/wiki/PostgreSQL_in_the_core</a></p>
<p>一、 安装依赖包</p>
<p>CentOS</p>
<p><code>yum install libpq-devel</code></p>
<p>Debian</p>
<p><code>sudo apt-get install libpq-dev</code></p>
<p>二、 配置.pc  libpq.pc</p>
<pre><code>export PKG_CONFIG_PATH=/usr/pgsql-9.3/lib/pkgconfig
export PATH=/usr/pgsql-9.3/bin:$PATH
./configure --enable-core-pgsql-support
</code></pre>
<p>三、 switch.conf.xml</p>
<p><code>html
&lt;param name=&#34;core-db-dsn&#34; value=&#34;pgsql://hostaddr=127.0.0.1 dbname=freeswitch user=freeswitch password= options=&#39;-c client_min_messages=NOTICE&#39; application_name=&#39;freeswitch&#39;&#34; /&gt;</code></p> <br/><hr/>上海老李，QQ:1354608370，FreeSWITCH  QQ群：
