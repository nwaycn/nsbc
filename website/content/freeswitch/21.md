# FreeSWITCH使用mysql等采用ODBC方式作为内核数据库


		<a href="21.html"><h1>FreeSWITCH使用mysql等采用ODBC方式作为内核数据库</h1></a>
                <br/><b>                <p>来自于： <a href="https://wiki.freeswitch.org/wiki/Using_ODBC_in_the_core" title="https://wiki.freeswitch.org/wiki/Using_ODBC_in_the_core">https://wiki.freeswitch.org/wiki/Using_ODBC_in_the_core</a></p>
<ol>
<li>Install unixODBC</li>
</ol>
<p><code>sudo apt-get install unixodbc-dev libmyodbc</code></p>
<ol>
<li>配置odbc</li>
</ol>
<p>/etc/odbc.ini for MySQL</p>
<pre><code>[freeswitch]
Driver      = /usr/lib64/odbc/libmyodbc.so
SERVER      = localhost
PORT        = 3306
DATABASE    = freeswitch   
OPTION      = 67108864
USER                = root            
PASSWORD    = password
</code></pre>
<p>/etc/odbcinst.ini for MySQL</p>
<pre><code>[MySQL]
Description = MySQL driver
Driver      = /usr/lib64/odbc/libmyodbc.so
Setup       = /usr/lib64/odbc/libodbcmyS.so
UsageCount  = 1
FileUsage       = 1
Threading       = 0
</code></pre>
<ol>
<li>测试ODBC</li>
</ol>
<p><code>isql -v freeswitch</code></p>
<p>如果正常会显示以下：</p>
<pre><code>+---------------------------------------+
| Connected!                            |
|                                       |
| sql-statement                         |
| help [tablename]                      |
| quit                                  |
|                                       |
+---------------------------------------+
SQL&gt;
</code></pre>
<ol>
<li>
<p>配置到FreeSWITCH中的DSN格式</p>
<p>DSN with username and password
<param name="core-db-dsn" value="database:username:password"/>
or
<param name="core-db-dsn" value="odbc://database:username:password"/></p>
</li>
</ol>
<p>配置相关的配置文件，如：</p>
<p>1.修改conf/autoload_configs中的db.conf.xml文件</p>
<pre><code>&lt;param name=&#34;odbc-dsn&#34; value=&#34;MYSQLTP:root:123456&#34;/&gt;
</code></pre>
<ol>
<li>修改conf/autoload_configs中的switch.conf.xml</li>
</ol>
<p>修改字段</p>
<pre><code>&lt;param name=&#34;core-db-dsn&#34; value=&#34;MYSQLTP:root:123456&#34; /&gt;
</code></pre>
<p>添加</p>
<pre><code>&lt;param name=&#34;odbc-dsn&#34; value=&#34;MYSQLTP:root:123456&#34;/&gt;
</code></pre>
<p>3.修改conf/autoload_configs中的voicemail.conf.xml</p>
<p>修改字段</p>
<pre><code>&lt;param name=&#34;odbc-dsn&#34; value=&#34;MYSQLTP:root:123456&#34;/&gt;
</code></pre>
<p>4.修改conf/autoload_configs中的callcenter.conf.xml</p>
<pre><code>&lt;param name=&#34;odbc-dsn&#34; value=&#34;MYSQLTP:root:123456&#34;/&gt;
</code></pre>
<p>5.修改conf/sip_profiles中的internal.xml 和external.xml，internal-ipv6.xml</p>
<pre><code>&lt;param name=&#34;odbc-dsn&#34; value=&#34;MYSQLTP:root:123456&#34;/&gt;
