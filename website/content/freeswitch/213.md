# debian10编译FreeSWITCH1.8


		<a href="213.html"><h1>debian10编译FreeSWITCH1.8</h1></a>
                <br/><b>                <p>注：需用debian网络版安装，不要装乱七八糟的界面等</p>
<p>apt-get update &amp;&amp; apt-get install -yq gnupg2 wget lsb-release</p>
<p>wget -O - https://files.freeswitch.org/repo/deb/debian-release/fsstretch-archive-keyring.asc | apt-key add -</p>
<p>echo &#34;deb http://files.freeswitch.org/repo/deb/debian-release/ <code>lsb_release -sc</code> main&#34; &gt; /etc/apt/sources.list.d/freeswitch.list</p>
<p>echo &#34;deb-src http://files.freeswitch.org/repo/deb/debian-release/ <code>lsb_release -sc</code> main&#34; &gt;&gt; /etc/apt/sources.list.d/freeswitch.list</p>
<p>apt-get update</p>
<p>apt-get build-dep freeswitch</p>
<p>cd /usr/src/</p>
<p>git clone -b v1.8 https://git.oschina.net/nwaycn/freeswitch.git</p>
<p>cd freeswitch</p>
<p>./bootstrap.sh -j</p>
<p>./configure</p>
<p>make</p>
