# Centos 7编译FreeSWITCH1.8


		<a href="214.html"><h1>Centos 7编译FreeSWITCH1.8</h1></a>
                <br/><b>                <p>```bash</p>
<p>yum install yum-utils</p>
<p>yum install -y https://files.freeswitch.org/repo/yum/centos-release/freeswitch-release-repo-0-1.noarch.rpm epel-release</p>
<p>yum-builddep -y freeswitch</p>
<p>yum install -y yum-plugin-ovl centos-release-scl rpmdevtools yum-utils git</p>
<p>yum install -y devtoolset-4-gcc*</p>
<p>scl enable devtoolset-4 &#39;bash&#39;</p>
<p>cd /usr/local/src</p>
<p>git clone -b v1.8 https://git.oschina.net/nwaycn/freeswitch.git</p>
<p>cd /usr/local/src/freeswitch</p>
<p>./bootstrap.sh -j</p>
<p>./configure --enable-portable-binary \
            --prefix=/usr --localstatedir=/var --sysconfdir=/etc \
            --with-gnu-ld --with-python --with-erlang --with-openssl \
            --enable-core-odbc-support --enable-zrtp</p>
<p>make</p>
<p>make -j install</p>
<p>make -j cd-sounds-install</p>
<p>make -j cd-moh-install
```</p>
<p>```bash</p>
<p>注：如果要编译mod_av，则需要以下步骤</p>
<p>wget http://download1.rpmfusion.org/free/el/updates/7/x86_64/x/x264-libs-0.148-24.20170521gitaaa9aa8.el7.x86_64.rpm</p>
<p>wget http://download1.rpmfusion.org/free/el/updates/7/x86_64/x/x264-devel-0.148-24.20170521gitaaa9aa8.el7.x86_64.rpm</p>
<p>rpm -hiv x264-libs-0.148-24.20170521gitaaa9aa8.el7.x86_64.rpm</p>
<p>rpm -hiv x264-devel-0.148-24.20170521gitaaa9aa8.el7.x86_64.rpm</p>
<p>cd /usr/local/src/freeswitch/libs</p>
<p>git clone https://gitee.com/nwaycn/libav.git</p>
<p>cd libav</p>
<p>./configure --enable-pic --enable-shared  --enable-libx264 --enable-gpl --extra-libs=&#34;-ldl&#34; </p>
<p>make   </p>
<p>make install</p>
<pre><code>cp /usr/local/lib/pkgconfig/libavcodec.pc    /usr/lib64/pkgconfig/
cp /usr/local/lib/pkgconfig/libavdevice.pc   /usr/lib64/pkgconfig/
cp /usr/local/lib/pkgconfig/libavfilter.pc   /usr/lib64/pkgconfig/
cp /usr/local/lib/pkgconfig/libavformat.pc   /usr/lib64/pkgconfig/
cp /usr/local/lib/pkgconfig/libavresample.pc /usr/lib64/pkgconfig/
cp /usr/local/lib/pkgconfig/libavutil.pc     /usr/lib64/pkgconfig/
cp /usr/local/lib/pkgconfig/libswscale.pc    /usr/lib64/pkgconfig/
ldconfig
</code></pre>
<p>然后 </p>
<p>cd /usr/src/freeswitch</p>
<p>重新编译freeswitch
```</p> <br/><hr/>上海老李，QQ:1354608370，FreeSWITCH  QQ群：
