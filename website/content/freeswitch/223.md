# 直接使用Nwayacd排队机的方法及postgresql12.7编译


		<a href="223.html"><h1>直接使用Nwayacd排队机的方法及postgresql12.7编译</h1></a>
                <br/><b>                <p>mod_nwayacd模块详解</p>
<h1>简述</h1>
<p>​        这些年排队机经历过好多个版本，此版本为架构的变化。</p>
<p>2014年时使用c++ esl outbound. </p>
<p>2015年golang esl outbound .</p>
<p>2017年golnag esl inbound  </p>
<p>2018年c语言mod_nwayacd.</p>
<p>当前为mod_nwayacd，已用于各式各样的呼叫中心场景中，不论外呼还是呼入均可用。但由于之前是需要使用宁卫的cti做对接才可以，所以现在我们升级下，可以脱离宁卫fsgui/cti实现相关的能力。当然需要安装postgresql 12.7及以上的版本，建议不要使用yum，而是自己手工编译postgresql.然后需要把nwaycc.sql导入，余下那么就可以按以下方式对接啦。</p>

<h1>附2 postgresql12.7 手工编译</h1>
<p>CentOS 6.3 Minimal 源码安装 PostgreSQL 9.2.3</p>
<p>环境：CentOS 6.3 最小化缺省安装，配置好网卡。</p>
<p>安装PostgreSQL前，确认Internet连接正常，以便下载安装文件。</p>
<p>先使用 yum -y update 指令升级系统到最新版本。</p>
<p>本安装将PostgreSQL的数据文件与执行文件分离，如果你打算设置到不同的路径，注意修改对应的执行命令和数据库初始化脚本。</p>
<p>＃ 修改防火墙设置，打开5432端口
vi /etc/sysconfig/iptables
-A INPUT -m state --state NEW -m tcp -p tcp --dport 5432 -j ACCEPT</p>
<p>＃ 重启防火墙使新设置生效
service iptables restart</p>
<p>＃ 新增用户组
groupadd postgres</p>
<p>＃ 新增用户
useradd postgres -g postgres</p>
<p>＃ 新建数据库执行文件目录
mkdir -p /usr/local/pgsql</p>
<p>＃ 新建数据库数据文件目录
mkdir -p /db/pgsql/data</p>
<p>＃ 修改目录拥有者
chown -R postgres /usr/local/pgsql/.</p>
<p>chown -R postgres /db/pgsql/data/</p>
<p>＃ 编辑PATH搜索路径
vi /etc/profile
Append these 2 lines to the end of the file:
PATH=/usr/local/pgsql/bin:$PATH
export PATH</p>
<p>＃ 生效PATH搜索路径
source /etc/profile</p>
<p>＃ 安装编译源码所需的工具和库
yum -y install wget gcc readline-devel zlib-devel make</p>
<p>debian

<p>＃ 进入源码压缩包下载目录
cd /usr/src</p>
<p>＃ 下载源码压缩包
wget https://ftp.postgresql.org/pub/source/v12.7/postgresql-12.7.tar.gz</p>
<p>＃ 解压缩源码包
tar zxvf ./postgresql-12.7.tar.gz</p>
<p>＃ 进入解压缩源码目录
cd ./postgresql-12.7</p>
<p>＃ 执行源码编译配置脚本
./configure</p>
<p>＃ 编译源码
make</p>
<p>＃ 安装
make install</p>
<p>＃ 变更登录用户
su - postgres</p>
<p>＃ 执行数据库初始化脚本
/usr/local/pgsql/bin/initdb --encoding=utf8 -D /db/pgsql/data</p>
<p>＃ 退出变更登录
exit</p>
