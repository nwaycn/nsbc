<p>由于这个token的相关的认证需求，请求的token必须以：
Authorization:Nway 打头，空格后跟</p>
<p>&#34;Authorization:Nway eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJleHAiOjE2OTg0NTcyOTEsImlkIjoiYWRtaW4iLCJvcmlnX2lhdC

</code></pre>
<p>在后续文档中，为了让请求命令看得更容易，以上字符串采用以下替代</p>
<pre><code>&#34;Authorization:Nway token&#34;
</code></pre>
<p><strong>三、接口</strong></p>
<ol>
<li>login</li>
</ol>
<p>调用方向服务器通过认证方式来获取token</p>
<p>请求值</p>
<pre><code> curl -d &#39;{&#34;username&#34;: &#34;admin&#34;, &#34;password&#34;: &#34;admin&#34;}&#39; -H &#34;Content-Type:application/json&#34; http://ip:port/api/login
</code></pre>
<p>返回值</p>
<p>错误值：
    { 
        &#34;Error&#34;: &#34;Not Authorized&#34; 
    }</p>
<p>正确值：</p>
<pre><code>{ 
&#34;token&#34;: 
&#34;eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJleHAiOjE2OTg0NTcxMTksImlkIjoiYWRtaW4iLCJvcmlnX2l
 4EC5ap8yQfcnskZoDN-IHjUa-wKiRYs&#34; 
}
</code></pre>
<p>2.get_uuid</p>
<p>用于从服务器获取一个uuid,如果是外呼等，建议使用此接口获取uuid
请求值</p>
<pre><code>curl  -H &#34;Authorization:Nway token&#34; http://127.0.0.1:8085/api/get_uuid
</code></pre>
<p>返回值
    { 
      &#34;result&#34;: &#34;success&#34;, 
      &#34;uuid&#34;: &#34;e0209523-fe05-4dc5-ae78-9d834d39d0cf&#34; 
    }</p>
<p>异常返回值</p>
<p>3.heartbeat</p>
<p>定时向服务器发送请求，用来探测服务器和调用方的心跳
请求值</p>
<pre><code>curl  -H &#34;Authorization:Nway token&#34; http://127.0.0.1:8085/api/heartbeat
</code></pre>
<p>返回值</p>
<pre><code>{ 
  &#34;result&#34;: &#34;success&#34; 
}
</code></pre>
<p>4.get_phone_uuid</p>
<p>用于从服务端获取一个正在通话中的电话的通话中的uuid，切记，如不在通话中则不会存在</p>
<p>请求值</p>
<pre><code>curl  -H &#34;Authorization:Nway token&#34; http://127.0.0.1:8085/api/get_phone_uuid
</code></pre>
<p>返回值</p>
<pre><code> { 
  &#34;result&#34;: &#34;success&#34;, 
  &#34;uuid&#34;: &#34;e0209523-fe05-4dc5-ae78-9d834d39d0cf&#34; 
}
</code></pre>
<p>如无通话，那么返回值为：</p>
<pre><code>{ 
  &#34;result&#34;: &#34;failed&#34;, 
  &#34;uuid&#34;: &#34;&#34; 
}
</code></pre>
<p>4.hangup</p>
<p>用于将一个正在通话中的电话给强行挂断</p>
<p>请求值</p>
<pre><code>curl -H &#34;Authorization:Nway token&#34; http://127.0.0.1:8085/api/hangup/10086
</code></pre>
<p>返回值</p>
<pre><code>{ 
  &#34;result&#34;: &#34;success&#34; 
  }
</code></pre>
<p>异常情况</p>
<p><code>{ 
  &#34;result&#34;: &#34;failed&#34;, 
  &#34;info&#34;: &#34;not found phone call&#34; 
  }</code></p>
