# NwayAI6.8.3发布了


		<a href="239.html"><h1>NwayAI6.8.3发布了</h1></a>
                <br/><b>                <p>更新日志：</p>
<ol>
<li>
<p>新增导入号码线程控制参数在web conf/app.conf中的</p>
<p>import_thread=10</p>
</li>
<li>
<p>新增vad参数，用于在放音前多少秒不做识别和处理</p>
</li>
</ol>
<p>autoload_configs/vad.conf.xml的</p>
<pre><code>&lt;param name=&#34;mode2_early_interval&#34; value=&#34;3&#34;/&gt;

&lt;!--代表3秒，如果为0，则不启用--&gt;
</code></pre>
<ol>
<li>将话术处理由原定义的|分隔符，^作为间断连接符，如：</li>
</ol>
<p>老李^在不|李浩^在不  </p>
<p>这样的字符串处理改为基于golang RE2的正则表达式处理</p>
<ol>
<li>
<p>在话术配置处置放链接下载话术正则表达式匹配工具</p>
</li>
<li>
<p>改进其它bug</p>
</li>
<li>
<p>识别asr改为宁卫离线ASR 配置文件为 nway.com.cn.conf</p>
</li>
</ol>
