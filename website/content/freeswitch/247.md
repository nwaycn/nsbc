# 小号平台手册


		<a href="247.html"><h1>小号平台手册</h1></a>
                <br/><b>                <p>一：平台基本功能</p>
<p>1.AXB绑定关系</p>
<p>由本平台管理AXB绑定关系，而非由运营商隐私号平台管理</p>
<p>2.智能选号（送a打哪显哪）</p>
<p>外显号码优先级从高到低为：被叫归属城市号码、被叫归属省会城市号码、外省大城市号码（北京、上海、广州）、随机</p>
<p>3.呼频管理</p>
<p>针对不同的小号平台的规则做呼叫限制，包括AX对的日绑定频次，X号码的日呼叫次数限制，X并发限制，以及可用时间段限制。</p>
<p>4.出局管理</p>
<p>支持改写主被叫规则,直接落地出局。</p>
<p>5.绑定日志</p>
<p>线路的绑定日志,主叫、被叫、x路、呼叫时间的绑定日志</p>
<p>6.多线路对接</p>
<p>支持多线路对接</p>
<p>7.智能路由(送x)</p>
<p>同一落地线路或不同线路,均可组成集群线路,优先走某一线路，线路并发跑满自动切换到另一路</p>
<p>8.平台区分</p>
<p>平台可以选择送a或者送x，需要提前说明，如果送a可以轮选x       或者智能选号打哪显哪规则，送x可以轮选a路，做智能路由</p>
