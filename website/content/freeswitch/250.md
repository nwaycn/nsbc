<p>二、配置
在nacd.conf.xml中主要关心</p>
<pre><code>&lt;configuration name=&#34;nacd.conf&#34; description=&#34;Nway ACD Module&#34;&gt;
  &lt;settings&gt;
    &lt;!-- 分机注册相关配置 --&gt;
    &lt;param name=&#34;db_type&#34; value=&#34;postgres&#34;/&gt; &lt;!-- 支持postgres和mysql --&gt;
    &lt;param name=&#34;db_string&#34; value=&#34;postgres://postgres:Nway2017@127.0.0.1/cloudcc_web?sslmode=disable&#34;/&gt;
    &lt;param name=&#34;ext_query_string&#34; value=&#34;SELECT extension_pswd FROM nway_extension WHERE extension_number = $1&#34;/&gt;
  &lt;/settings&gt;
&lt;/configuration&gt;
</code></pre>
<p>注意：其它部分和认证功能无关，包括授权等，都和认证这部分无关，直接使用即可</p>
<p>配置说明：</p>
<pre><code>db_type：指定数据库类型，支持 postgres 和 mysql。根据所使用的数据库类型，mod_nacd 会进行相应处理。

db_string：数据库连接字符串，这里使用了 PostgreSQL 的标准连接格式。连接字符串格式需要与数据库类型一致。

ext_query_string：查询语句，用于查找分机的密码。$1 是查询参数，用来替代分机号码，模块将会使用此语句从数据库中获取用户的注册信息。
</code></pre>

<p>四、核心功能：静态编译和自定义数据库结构</p>
<ul>
<li>
<p>mod_nacd 的核心特点是使用静态编译，通过集成数据库查询功能的 Go 代码，避免了对 MySQL 或 PostgreSQL C 客户端库的依赖。这种方式的优势在于：</p>
</li>
<li>
<p>减少依赖：无需安装额外的数据库客户端库，模块可以直接与数据库通信。</p>
</li>
<li>
<p>灵活性：用户可以自定义查询语句和表结构，使得模块能够适配不同的数据库设计。</p>
</li>
</ul>
<p>模块的数据库交互功能通过静态编译后的 Go 库（如 libndb_conn.a）实现，这个库包含了数据库连接和查询的逻辑，编译为 .a 文件后直接嵌入到模块中，保证了独立性。</p>

<p>代替到现在还有人要用lua或xml等进行数据库和FreeSWITCH的账号间的处理，配置相对而言过于麻烦。</p>
