<h2>系统概述</h2>
<p>Nway IP Security Manager 是一个基于Web的内核级IP安全管理平台，针对sip协议进行安全防护，用于配置和管理nip_ctl内核模块。该系统提供了直观的用户界面来管理IP黑白名单、用户代理过滤规则、查看安全日志以及配置系统参数。</p>
<h3>主要功能</h3>
<ul>
<li>用户认证和会话管理</li>
<li>IP黑白名单文件管理</li>
<li>用户代理(UA)黑白名单管理</li>
<li>实时安全日志查看和过滤</li>
<li>系统配置管理</li>
<li>NIP内核模块配置</li>
<li>多语言支持（中文/英文）</li>
</ul>
<hr/>
<h2>登录系统</h2>
<h3>访问系统</h3>
<ol>
<li>打开Web浏览器</li>
<li>在地址栏输入系统URL（默认为：http://localhost:8080）</li>
<li>按回车键访问登录页面</li>
</ol>
<h3>登录界面</h3>
<p>登录页面包含以下元素：
- 用户名输入框
- 密码输入框
- CAPTCHA验证码图片
- 验证码输入框
- 语言选择下拉菜单
- 登录按钮</p>
<h3>登录步骤</h3>
<ol>
<li>在用户名输入框中输入默认用户名：<code>admin</code></li>
<li>在密码输入框中输入默认密码：<code>admin123</code></li>
<li>查看CAPTCHA验证码图片并输入显示的4位数字验证码</li>
<li>（可选）使用语言选择器切换界面语言（中文/英文）</li>
<li>点击&#34;登录&#34;按钮</li>
</ol>
<blockquote>
<p><strong>注意</strong>：首次登录后应立即修改默认密码以确保系统安全。</p>
</blockquote>
<h3>登录安全</h3>
<p>系统采用以下安全措施：
- CAPTCHA验证码防止暴力破解
- 会话管理确保用户身份验证
- 自动会话超时（24小时）</p>
<hr/>
<h2>仪表盘</h2>
<p>登录成功后，系统将自动跳转到仪表盘页面。仪表盘提供了系统概览和快速访问入口。</p>
<h3>仪表盘组件</h3>
<h4>文件管理卡片</h4>
<ul>
<li>显示管理的文件数量</li>
<li>提供直接跳转到文件管理页面的链接</li>
</ul>
<h4>系统设置卡片</h4>
<ul>
<li>提供密码修改功能</li>
<li>直接跳转到设置页面的链接</li>
</ul>
<h4>安全初始化卡片</h4>
<ul>
<li>运行 <code>nip_ctl init --config nip.conf</code> 命令，此命令是需要在NIP服务设置完成后执行</li>
<li>初始化安全配置</li>
</ul>
<h4>Web服务设置卡片</h4>
<ul>
<li>配置 <code>nway_safer.service</code> 以实现自动启动</li>
<li>设置Web服务开机自启</li>
</ul>
<h4>NIP服务设置卡片</h4>
<ul>
<li>配置和部署 <code>nip.service</code></li>
<li>根据内核版本复制相应文件并设置服务，会进行一次安全初始化</li>
</ul>
<h4>最近活动区域</h4>
<ul>
<li>显示系统最近的操作记录</li>
<li>包含时间、操作类型、目标和状态信息</li>
</ul>
<h4>系统信息区域</h4>
<ul>
<li>显示服务器端口等配置信息</li>
</ul>
<h3>仪表盘操作</h3>
<ol>
<li><strong>初始化安全配置</strong>：点击&#34;运行初始化&#34;按钮执行 <code>nip_ctl init</code> 命令</li>
<li><strong>设置Web服务</strong>：点击&#34;设置服务&#34;按钮配置Web服务自启动</li>
<li><strong>设置NIP服务</strong>：点击&#34;设置服务&#34;按钮配置NIP内核服务</li>
</ol>
<hr/>
<h2>文件管理</h2>
<p>文件管理页面用于管理所有与安全相关的配置文件，包括IP黑白名单、用户代理过滤规则等。</p>
<h3>管理的文件类型</h3>
<ol>
<li><strong>custom_white_ip.txt</strong> - 自定义白名单IP地址</li>
<li><strong>ip_black.txt</strong> - 黑名单IP地址</li>
<li><strong>region_white_ip.txt</strong> - 区域白名单IP地址</li>
<li><strong>src_black.txt</strong> - 源地址黑名单</li>
<li><strong>dst_black.txt</strong> - 目标地址黑名单</li>
<li><strong>ua_black.txt</strong> - 用户代理黑名单</li>
<li><strong>ua_white.txt</strong> - 用户代理白名单</li>
<li><strong>license.txt</strong> - 授权许可证文件</li>
</ol>
<h3>文件管理操作</h3>
<h4>查看文件列表</h4>
<ul>
<li>左侧面板显示所有管理的文件</li>
<li>显示每个文件的名称、描述、行数和大小</li>
</ul>
<h4>编辑文件</h4>
<ol>
<li>在左侧文件列表中点击要编辑的文件</li>
<li>文件内容将加载到右侧编辑器中</li>
<li>在编辑器中修改文件内容</li>
<li>点击&#34;保存&#34;按钮保存更改</li>
</ol>
<h4>添加条目</h4>
<ol>
<li>选择要编辑的文件</li>
<li>点击&#34;添加条目&#34;按钮</li>
<li>在弹出的对话框中输入新条目</li>
<li>点击确定添加到文件中</li>
</ol>
<h4>查看文件统计</h4>
<ul>
<li>显示文件的详细统计信息</li>
<li>包括存在状态、大小、行数、唯一条目数等</li>
</ul>
<h4>获取机器码</h4>
<ol>
<li>点击&#34;获取机器码&#34;按钮</li>
<li>系统将执行 <code>nway_machine_id</code> 命令</li>
<li>显示机器码并提供复制功能</li>
</ol>
<h4>运行应用</h4>
<ul>
<li>点击&#34;Run Application&#34;按钮执行 <code>nip_ctl --config nip.conf</code> 命令</li>
</ul>
<hr/>
<h2>日志查看器</h2>
<p>日志查看器页面用于查看和分析系统安全日志，帮助管理员监控和分析安全事件。</p>
<h3>日志过滤选项</h3>
<h4>时间范围</h4>
<ul>
<li>全部时间</li>
<li>最近1小时</li>
<li>最近24小时</li>
<li>最近7天</li>
</ul>
<h4>IP地址过滤</h4>
<ul>
<li>输入特定IP地址进行过滤</li>
</ul>
<h4>From字段过滤</h4>
<ul>
<li>根据SIP消息的From字段进行过滤</li>
</ul>
<h4>To字段过滤</h4>
<ul>
<li>根据SIP消息的To字段进行过滤</li>
</ul>
<h4>Reason过滤</h4>
<ul>
<li>根据阻止原因进行过滤：</li>
<li>ip_unknown - 未知IP地址</li>
<li>ip_black - IP黑名单</li>
<li>ua_black - 用户代理黑名单</li>
<li>dst_pat - 目标模式匹配</li>
<li>src_pat - 源模式匹配</li>
</ul>
<h4>搜索文本</h4>
<ul>
<li>在整个日志条目中搜索指定文本</li>
</ul>
<h3>日志统计</h3>
<p>日志查看器显示以下统计信息：
- IP黑名单条目数
- 未知IP条目数
- 用户代理黑名单条目数
- 目标模式匹配条目数
- 源模式匹配条目数
- 总过滤条目数</p>
<h3>日志条目显示</h3>
<p>每个日志条目包含以下信息：
- 时间戳
- 操作类型（DROP等）
- 源IP地址和端口
- 目标IP地址和端口
- 阻止原因
- 详细信息</p>
<h3>日志操作</h3>
<ol>
<li><strong>过滤日志</strong>：设置过滤条件后点击&#34;过滤&#34;按钮</li>
<li><strong>清除过滤器</strong>：点击&#34;清除过滤器&#34;按钮重置所有过滤条件</li>
<li><strong>刷新日志</strong>：点击&#34;刷新&#34;按钮重新加载日志</li>
<li><strong>分页浏览</strong>：使用底部的分页控件浏览不同页面的日志</li>
</ol>
<hr/>
<h2>系统设置</h2>
<p>系统设置页面用于配置应用程序参数和修改用户密码。</p>
<h3>应用配置</h3>
<h4>修改服务器端口</h4>
<ol>
<li>在&#34;Server Port&#34;输入框中输入新的端口号（1-65535）</li>
<li>点击&#34;保存配置&#34;按钮</li>
</ol>
<h4>修改用户名</h4>
<ol>
<li>在&#34;Username&#34;输入框中输入新的用户名</li>
<li>点击&#34;保存配置&#34;按钮</li>
</ol>
<h3>密码修改</h3>
<ol>
<li>在&#34;新密码&#34;输入框中输入新密码（至少6个字符）</li>
<li>在&#34;确认密码&#34;输入框中再次输入新密码</li>
<li>点击&#34;修改密码&#34;按钮</li>
</ol>
<blockquote>
<p><strong>注意</strong>：密码修改后需要重新登录系统。</p>
</blockquote>
<hr/>
<h2>故障排除</h2>
<h3>常见问题</h3>
<h4>无法登录系统</h4>
<ul>
<li>检查用户名和密码是否正确</li>
<li>确认CAPTCHA验证码输入正确</li>
<li>清除浏览器缓存和Cookie后重试</li>
</ul>
<h4>文件保存失败</h4>
<ul>
<li>检查文件路径是否正确</li>
<li>确认系统有文件写入权限</li>
<li>检查磁盘空间是否充足</li>
</ul>
<h4>日志无法显示</h4>
<ul>
<li>确认 <code>/var/log/nip_kmod.log</code> 文件存在</li>
<li>检查文件读取权限</li>
<li>确认nip_kmod内核模块正在运行</li>
</ul>
<h4>服务设置失败</h4>
<ul>
<li>确认在Linux系统上运行</li>
<li>检查是否有root权限</li>
<li>确认systemd服务管理器可用</li>
</ul>
<h3>系统要求</h3>
<h4>操作系统</h4>
<ul>
<li>Linux发行版（推荐CentOS 7.9, Debian 12, Ubuntu 24, openEuler 22等）</li>
<li>Windows（仅用于开发和测试）</li>
</ul>
<h4>硬件要求</h4>
<ul>
<li>CPU: 1 GHz或更高</li>
<li>内存: 1 GB RAM（推荐2 GB或更高）</li>
<li>硬盘空间: 100 MB可用空间</li>
</ul>
<h4>软件依赖</h4>
<ul>
<li>systemd服务管理器（Linux）</li>
</ul>
