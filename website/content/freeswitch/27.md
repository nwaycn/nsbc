# FreeSWITCH1.6使用postgresql9.3.5作为数据库编译过程


		<a href="27.html"><h1>FreeSWITCH1.6使用postgresql9.3.5作为数据库编译过程</h1></a>
                <br/><b>                <h1>加QQ群： 293697898 和更多群友一起成长</h1>
<p>在之前，我们转载了FreeSWITCH官网上有关postgresql的配置的问题，但是在细节上并没有描述，现在就如何在debian8.1上安装FreeSWITCH、Postgresql并使用Postgresql作为FreeSWITCH数据库做个简单介绍。</p>
<p>第一步、安装Postgresql</p>
<p>CentOS 或debian 源码安装 PostgreSQL 9.3.5</p>
<p>安装PostgreSQL前，确认Internet连接正常，以便下载安装文件。</p>
<p>先使用 yum -y update 指令升级系统到最新版本。</p>
<p>本安装将PostgreSQL的数据文件与执行文件分离，如果你打算设置到不同的路径，注意修改对应的执行命令和数据库初始化脚本。</p>
<p>＃ 修改防火墙设置，打开5432端口</p>
<p><code>vi /etc/sysconfig/iptables
-A INPUT -m state --state NEW -m tcp -p tcp --dport 5432 -j ACCEPT</code></p>
<p>＃ 重启防火墙使新设置生效</p>
<p><code>service iptables restart</code></p>
<p>＃ 新增用户组</p>
<p><code>groupadd postgres</code></p>
<p>＃ 新增用户</p>
<p><code>useradd postgres -g postgres</code></p>
<p>＃ 新建数据库执行文件目录</p>
<p><code>mkdir -p /usr/local/pgsql</code></p>
<p>＃ 新建数据库数据文件目录</p>
<p><code>mkdir -p /db/pgsql/data</code></p>
<p>＃ 修改目录拥有者</p>
<pre><code>chown -R postgres /usr/local/pgsql/.
chown -R postgres /db/pgsql/data
chown -R postgres /db/pgsql/data/.
</code></pre>
<p>＃ 编辑PATH搜索路径</p>
<pre><code>vi /etc/profile
</code></pre>
<p>Append these 2 lines to the end of the file:</p>
<pre><code>PATH=/usr/local/pgsql/bin:$PATH
export PATH
</code></pre>
<p>＃ 生效PATH搜索路径</p>
<pre><code>source /etc/profile
</code></pre>
<p>＃ 安装编译源码所需的工具和库</p>
<pre><code>yum -y install wget gcc readline-devel zlib-devel make
</code></pre>
<p>debian </p>
<pre><code> apt-get install zlibc libghc-zlib-dev libzlcore-dev gcc make git automake
</code></pre>
<p>＃ 进入源码压缩包下载目录</p>
<pre><code>cd /usr/src
</code></pre>
<p>＃ 下载源码压缩包</p>
<pre><code>wget http://ftp.postgresql.org/pub/source/v9.3.5/postgresql-9.3.5.tar.gz
</code></pre>
<p>＃ 解压缩源码包</p>
<pre><code>tar zxvf ./postgresql-9.3.5.tar.gz
</code></pre>
<p>＃ 进入解压缩源码目录</p>
<pre><code>cd ./postgresql-9.3.5
</code></pre>
<p>＃ 执行源码编译配置脚本</p>
<pre><code>./configure
</code></pre>
<p>＃ 编译源码</p>
<pre><code>make
</code></pre>
<p>＃ 安装</p>
<pre><code>make install
</code></pre>
<p>＃ 变更登录用户</p>
<pre><code>su - postgres
</code></pre>
<p>＃ 执行数据库初始化脚本</p>
<pre><code>/usr/local/pgsql/bin/initdb --encoding=utf8 -D /db/pgsql/data
</code></pre>
<p>＃ 退出变更登录</p>
<pre><code>exit
</code></pre>
<p>＃ 复制PostgreSQL执行脚本</p>
<pre><code>cp /usr/src/postgresql-9.3.5/contrib/start-scripts/linux /etc/init.d/postgresql
</code></pre>
<p>＃ 增加执行权限</p>
<pre><code>chmod +x /etc/init.d/postgresql
</code></pre>
<p>＃ 编辑PostgreSQL执行脚本，指定数据库文件目录</p>
<pre><code>vi /etc/init.d/postgresql
PGDATA=&#34;/db/pgsql/data&#34;
</code></pre>
<p>＃ 编辑配置文件，配置可访问数据库的网络地址
(注意别忘了去掉#listen_addresses=前面的#)</p>
<pre><code>vi /db/pgsql/data/postgresql.conf
listen_addresses = &#39;*&#39;
</code></pre>
<p>＃ 启动PostgreSQL服务</p>
<pre><code>service postgresql start
</code></pre>
<p>＃ 以postgres用户登录数据库，修改postgres用户的数据库密码</p>
<pre><code>psql -U postgres
 postgres=# ALTER USER postgres PASSWORD &#39;123456&#39;;
  postgres=# \q
</code></pre>
<p>退出pg登录</p>
<pre><code>exit
</code></pre>
<p>＃ 编辑配置文件，设置密码md5验证</p>
<pre><code>vi /db/pgsql/data/pg_hba.conf
# &#34;local&#34; is for Unix domain socket connections only
local all all md5
# IPv4 local connections:
#host all all 127.0.0.1/32 trust
host all all 0.0.0.0/0 md5
</code></pre>
<p>＃ 重启数据库服务</p>
<pre><code>service postgresql restart
</code></pre>
<p>debian下需要安装 chkconfig工具</p>
<p>设置开机自动启动服务</p>
<pre><code>chkconfig postgresql on
</code></pre>
<p>配置LD_LIBRARY_PATH
<code>vi /etc/profile</code></p>
<pre><code>LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/usr/local/pgsql/lib
export LD_LIBRARY_PATH

C_INCLUDE_PATH=$C_INCLUDE_PATH:/usr/local/pgsql/include
export C_INCLUDE_PATH
</code></pre>
<p><code>source /etc/profile</code></p>
<p>二、 安装FreeSWITCH</p>
<ol>
<li>配置debian源</li>
</ol>
<p><code>vim /etc/apt/sources.list</code></p>
<p>变成以下内容：</p>
<pre><code>\# deb cdrom:[Debian GNU/Linux 8.1.0 _Jessie_ - Official amd64 DVD Binary-1 20150606-14:19]/ jessie contrib main

\# deb cdrom:[Debian GNU/Linux 8.1.0 _Jessie_ - Official amd64 DVD Binary-1 20150606-14:19]/ jessie contrib main

\# deb http://security.debian.org/ jessie/updates main contrib
\# deb-src http://security.debian.org/ jessie/updates main contrib

deb http://mirrors.163.com/debian jessie main non-free contrib
deb http://mirrors.163.com/debian jessie-proposed-updates main contrib non-free
deb http://mirrors.163.com/debian-security jessie/updates main contrib non-free

deb http://security.debian.org jessie/updates main contrib non-free
\# 以上禁掉cdrom和deb原生源，改为163的，加快速度
\# jessie-updates, previously known as &#39;volatile&#39;
\# A network mirror was not selected during install. The following entries
\# are provided as examples, but you should amend them as appropriate
\# for your mirror of choice.
\#
\# deb http://ftp.debian.org/debian/ jessie-updates main contrib
\# deb-src http://ftp.debian.org/debian/ jessie-updates main contrib
</code></pre>
<ol>
<li>下载并编译 
a. 添加freeswitch的源
<code>echo &#34;deb http://files.freeswitch.org/repo/deb/debian/ jessie main&#34; &gt; /etc/apt/sources.list.d/99FreeSWITCH.test.list</code>
<code>wget -O - http://files.freeswitch.org/repo/deb/debian/key.gpg |apt-key add -</code>
<code>apt-get update</code></li>
</ol>
<p>b. 安装依赖
<code>DEBIAN_FRONTEND=none APT_LISTCHANGES_FRONTEND=none apt-get install -y --force-yes freeswitch-video-deps-most</code></p>
<p>c. git FreeSWITCH的源码</p>
<pre><code>git config --global pull.rebase true
git clone https://freeswitch.org/stash/scm/fs/freeswitch.git freeswitch.git
cd freeswitch.git
./bootstrap.sh -j
</code></pre>
<p>d. 在modules.conf中开启pg_cdr
<code>vim modules.conf</code></p>
<p>去掉 mod_cdr_pg_csv 前的#</p>
<p>e. 编译并install</p>
<pre><code>./configure --enable-core-pgsql-support 
    make
    make install
    make cd-sounds-install 
    make cd-moh-install 
    make samples
</code></pre>
<p>f. 配置FreeSWITCH使用Postgresql</p>
<pre><code> &lt;param name=&#34;odbc-dsn&#34; value=&#34;pgsql://hostaddr=127.0.0.1 dbname=freeswitch user=postgres password=&#39;123456&#39; options=&#39;-c client_min_messages=NOTICE&#39; application_name=&#39;freeswitch&#39;&#34; /&gt;
</code></pre>
<p>这就是置于FreeSWITCH中的pg配置</p>
<p>如db.conf.xml:</p>
<pre><code> &lt;configuration name=&#34;db.conf&#34; description=&#34;LIMIT DB Configuration&#34;&gt;
  &lt;settings&gt;
    &lt;!--&lt;param name=&#34;odbc-dsn&#34; value=&#34;dsn:user:pass&#34;/&gt;--&gt;
    &lt;param name=&#34;odbc-dsn&#34; value=&#34;pgsql://hostaddr=127.0.0.1 dbname=freeswitch user=postgres password=&#39;123456&#39; options=&#39;-c client_min_messages=NOTICE&#39; application_name=&#39;freeswitch&#39;&#34; /&gt;
  &lt;/settings&gt;
&lt;/configuration&gt;
</code></pre>
<p>其余的配置文件如下：</p>
<pre><code>db.conf.xml
fifo.conf.xml
voicemail.conf.xml
switch.conf.xml
internal.xml
external.xml
</code></pre>
<p>配置cdr,先建立库及表</p>
<pre><code>su - postgres
psql -U postgres
\#postgres&gt; create database cdr;
\#postgres&gt; 
create table cdr (
    id                        serial primary key,
    local_ip_v4               inet not null,
    caller_id_name            varchar,
    caller_id_number          varchar,
    destination_number        varchar not null,
    context                   varchar not null,
    start_stamp               timestamp with time zone not null,
    answer_stamp              timestamp with time zone,
    end_stamp                 timestamp with time zone not null,
    duration                  int not null,
    billsec                   int not null,
    hangup_cause              varchar not null,
    uuid                      uuid not null,
    bleg_uuid                 uuid,
    accountcode               varchar,
    read_codec                varchar,
    write_codec               varchar,
    sip_hangup_disposition    varchar,
    ani                       varchar
);
\#postgres&gt;\q
exit
</code></pre>
<p>修改pg_cdr.conf.xml文件中的db-info</p>
<pre><code> &lt;param name=&#34;db-info&#34; value=&#34;host=localhost dbname=cdr user=postgres password=123456 connect_timeout=10&#34; /&gt;
</code></pre>
