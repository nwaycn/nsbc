# FreeSWITCH中将sip trace输出到日志文件中


		<a href="44.html"><h1>FreeSWITCH中将sip trace输出到日志文件中</h1></a>
                <br/><b>                <p>文库地址： https://wiki.freeswitch.org/wiki/Sofia-SIP</p>
<p>To have the SIP details put into the log file automatically on startup, add this to sofia.conf.xml:</p>
<pre><code>&lt;global_settings&gt;
  ...
  &lt;param name=&#34;tracelevel&#34; value=&#34;DEBUG&#34;/&gt;
  ...
&lt;/global_settings&gt;
</code></pre>
<p>and the following to the sip profile xml file:</p>
<pre><code>&lt;profiles&gt;
  ...
  &lt;profile name=&#34;...&#34;&gt;
    ...
    &lt;param name=&#34;sip-trace&#34; value=&#34;yes&#34;/&gt;
    ...
  &lt;/profile&gt;
  ...
&lt;/profiles&gt;
</code></pre> <br/><hr/>上海老李，QQ:1354608370，FreeSWITCH  QQ群：
