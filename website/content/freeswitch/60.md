# FreeSWITCH优化之一 -----使用内存数据库作为运行数据库`n`n		FreeSWITCH优化之一 -----使用内存数据库作为运行数据库
                                
Linux 下

备份原来的db
mv /usr/local/freeswitch/db /usr/local/freeswitch/db_old 
创建新的目录
mkdir /usr/local/freeswitch/db 
挂载内存库
mount -t tmpfs tmpfs /usr/local/freeswitch/db

WINDOWS下

使用相关工具，做一个内存盘
在磁盘中做一个基本的安装目录后，进行配置且保存
做一个服务，把磁盘中的安装目录拷到内存盘中，并运行freeswithconsole.exe即可。 上海李浩，QQ:1354608370，FreeSWITCH  QQ群：
