# FreeSWITCH优化之一 -----使用jemalloc等内存管理模块加快内存


		<a href="61.html"><h1>FreeSWITCH优化之一 -----使用jemalloc等内存管理模块加快内存</h1></a>
                <br/><b>                <p>a. 下载</p>
<p>https://github.com/jemalloc/jemalloc/archive/4.0.4.tar.gz</p>
<p>b. 解压</p>
<p>tar zxvf jemalloc-4.0.4.tar.gz</p>
<p>c. 编译</p>
<p>cd jemalloc-4.0.4</p>
<p>./configure --prefix=/usr/local</p>
<p>make</p>
<p>make install</p>
<p>d. 添加到etc/profile中</p>
<p>export LD_PRELOAD=/usr/local/lib/libjemalloc.so</p>
<p>保存后，source /etc/profile</p>
<p>这样在重启相关应用后，就会用Jemalloc等代替标准库的malloc等进行内存分配和释放</p> <br/><hr/>上海老李，QQ:1354608370，FreeSWITCH  QQ群：
