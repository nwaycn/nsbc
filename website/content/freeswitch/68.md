# FreeSWITCH中Openh264的编译和使用


		<a href="68.html"><h1>FreeSWITCH中Openh264的编译和使用</h1></a>
                <br/><b>                <h1>加QQ群： 293697898 和更多群友一起成长</h1>
<p>制作成rpm,参考：</p>
<p>https://freeswitch.org/confluence/display/FREESWITCH/Creating+RPM+repositary</p>
<p>在FreeSWITCH中有很多的第三方依赖库，而有相当一部分是安东尼等大神自己改过一些代码的，所以如果遇到了，可以到以下地址先看看有没有库： <a href="https://freeswitch.org/stash/projects/SD" title="https://freeswitch.org/stash/projects/SD">https://freeswitch.org/stash/projects/SD</a></p>
<p>而 Openh264则在这个Support Deps Projects中</p>
<p>下载编译，参考：<a href="http://www.8000hz.com/archives/freeswitch-1-7-openh264-mcu.html" title="http://www.8000hz.com/archives/freeswitch-1-7-openh264-mcu.html">http://www.8000hz.com/archives/freeswitch-1-7-openh264-mcu.html</a>
,如果有更多的需要了解，可以看README.MD文件</p>
<pre><code>git clone https://freeswitch.org/stash/scm/sd/openh264.git
cd openh264/
make ENABLE64BIT=Yes
make install
cp openh264.pc /usr/lib64/pkgconfig/

pkg-config --list-all | grep openh264
</code></pre>
<p>编译FreeSWITCH </p>
<pre><code>cd freeswitch

echo &#34;codecs/mod_openh264&#34; &gt;&gt; modules.conf

./configure --prefix=/usr/local/freeswitch
make 
make install
</code></pre>
<p>测试</p>
<p>一。修改autoload_configs/modules.conf.xml</p>
<p>注释   mod_h26x  添加  mod_openh264</p>
<p>二。修改  vars.xml  codec 中添加 H264 编码</p>
