# FreeSWITCH中的vpx,yuv 编译


		<a href="69.html"><h1>FreeSWITCH中的vpx,yuv 编译</h1></a>
                <br/><b>                <p>之前有群友说git中的编译不成功，我也折腾了一会，于是还是用files.freeswitch.org中的去用吧。</p>
<p>download:</p>
<pre><code>wget http://files.freeswitch.org/downloads/libs/libvpx-1.4.1.tar.gz

tar zxvf libvpx-1.4.1.tar.gz

cd libvpx-1.4.1

./configure --enable-pic --disable-static --enable-shared

make

make install

cp /usr/local/lib/pkgconfig/vpx.pc /usr/lib64/pkgconfig/
</code></pre>
<p>libyuv:</p>
<pre><code> git clone https://freeswitch.org/stash/scm/sd/libyuv.git

 cd libyuv

 make -f linux.mk CXXFLAGS=&#34;-fPIC -O2 -fomit-frame-pointer -Iinclude/&#34;

 make install

 cp /usr/lib/pkgconfig/libyuv.pc /usr/lib64/pkgconfig/
</code></pre> <br/><hr/>上海老李，QQ:1354608370，FreeSWITCH  QQ群：
