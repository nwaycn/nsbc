# 阿里云中Debian7.x64位系统中安装FusionPBX过程`n`n		阿里云中Debian7.x64位系统中安装FusionPBX过程
                                

下载安装脚本
cd /usr/src
wget https://raw.githubusercontent.com/fusionpbx/fusionpbx-scripts/master/install/ubuntu/install_fusionpbx.sh`n`n更改权限
chmod 755 install_fusionpbx.sh`n`n执行脚本
./install_fusionpbx.sh install-both user`n`n在此过程中，如果因为编译等原因不通过，则需要先执行一下安装相关第三方库`n`napt-get install autoconf automake devscripts gawk g++ git-core libjpeg-dev \
         libncurses5-dev libtool make python-dev gawk pkg-config libtiff5-dev \
         libperl-dev libgdbm-dev libdb-dev gettext libssl-dev libcurl4-openssl-dev \
         libpcre3-dev libspeex-dev libspeexdsp-dev libsqlite3-dev libedit-dev libldns-dev`n`n遇到编译不成功，有个原因是spandsp不通编译通过，然后又依赖于tiff,tiff又依赖于ldns,于是
cd /usr/src
wget http://www.nlnetlabs.nl/downloads/ldns/ldns-1.6.17.tar.gz
tar zxvf ldns-1.6.17.tar.gz
cd ldns.1.6.17
./configure &amp;&amp; make &amp;&amp; make install`n`n然后到freeswitch/libs/tiff和freeswitch/libs/spandsp下分别重新configure &amp;&amp; make &amp;&amp; make install`n`n再次运行./install_fusionpbx.sh时会发现又重新下载，那么就在.sh脚本中把下载freeswitch到cp freeswitch等代码注释掉。`n`n重新再执行install_fusionpbx.sh的脚本，如遇到选择数据库等的选S 即Sqlite`n`n后续相对应较为顺利些，但有些可能会因为git或wget等再遇到故障，那就ctrl c后再执行，一直到最后config.php前会提示 nginx或apache运行于某个地址，我安装时是阿里云内网地址，那么通过流览器访问 外网地址，则会出现https不安全的提示，忽略，然后按页面上的进示进行安装配置，就可以登录了，如果在fs_cli看到ipv6的问题，则在fusionpbx的advance 下的sip profiles中删掉ipv6相关的配置。`n`n一切结束，祝你好运！luck 上海李浩，QQ:1354608370，FreeSWITCH  QQ群：
