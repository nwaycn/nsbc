# FreeSWITCH同一个帐号多点注册和最大注册数且让同一分机同时振铃


		<a href="85.html"><h1>FreeSWITCH同一个帐号多点注册和最大注册数且让同一分机同时振铃</h1></a>
                <br/><b>                <p>原文：https://wiki.freeswitch.org/wiki/Sofia-SIP</p>
<p>Multiple Registrations
Call one extension and ring several phones
You must enable multiple registrations in conf/sip_profiles/internal-ipv6.xml and conf/sip_profiles/internal.xml (enabling the setting in conf/autoload_configs/switch.conf.xml had no effect).
Valid values for this parameter are &#34;contact&#34;, &#34;true&#34;, &#34;false&#34;. value=&#34;true&#34; is the most common use.
<param name="multiple-registrations" value="true"/>
Setting this value to &#34;contact&#34; will remove the old registration based on sip_user, sip_host and contact field as opposed to the call_id.
Ringing All Registered Extensions
In your dialplan (conf/dialplan/default.xml) you can now use the sofia_contact lookup function to return all registered sip profiles; for example in the default.xml in sections <extension name="Local_Extension"> and <extension name="extension-intercom"> replace:</extension></extension></p>
<p>&lt; extension name=&#34;extension-intercom&#34;&gt;</p>
<p>&lt; condition field=&#34;destination_number&#34; expression=&#34;^8(10[01][0-9])$&#34;&gt;</p>
<pre><code>  &lt; action application=&#34;set&#34; data=&#34;dialed_extension=$1&#34;/&gt;

  &lt; action application=&#34;export&#34; data=&#34;sip_auto_answer=true&#34;/&gt;

  &lt;!-- needed for multiple-registrations=true and multi extension ringing see: http://wiki.freeswitch.org/wi$
  &lt;!-- &lt;action application=&#34;bridge&#34; data=&#34;user/${dialed_extension}@${domain_name}&#34;/&gt; --&gt;

  &lt; action application=&#34;bridge&#34; data=&#34;${sofia_contact(${dialed_extension})}&#34;/&gt;
</code></pre>
<p>&lt; /condition&gt;</p>
<p>&lt; /extension&gt;</p>
<p>With the follwing:</p>
<p>&lt; action application=&#34;bridge&#34; data=&#34;${sofia_contact(${dialed_extension})}&#34;/&gt;</p>
