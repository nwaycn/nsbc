# kamailio 在debian上安装及安装其GUI,siremis


		<a href="31.html"><h1>kamailio 在debian上安装及安装其GUI,siremis</h1></a>
                <br/><b>                <p>debian 8.2 64位虚拟机</p>
<h1>特别注意： 每个人在不同的系统，或者相同的系统，不同的时间可能遇到的问题可能不一样，所以这篇文章只能作为参考，而不是绝对成功的教程。</h1>
<h3>一 、 Kamailio安装</h3>
<p>上海老李</p>
<p>1 . 安装必要的安装包 </p>
<pre><code>apt-get install git-core
apt-get install gcc
apt-get install flex
apt-get install bison
apt-get install make
apt-get install libmysqlclient-dev
apt-get install libssl-dev
</code></pre>
<p>2 . 安装mysql server</p>
<pre><code>apt-get install mysql-server
</code></pre>
<p>注：记住mysql server的root密码，当然也可以空密码</p>
<p>3 . 获取源代码</p>
<pre><code>mkdir -p /usr/local/src/kamailio 
cd /usr/local/src/kamailio
</code></pre>
<p>Download the sources from GIT using the following commands.</p>
<pre><code>git clone --depth 1 git://git.kamailio.org/kamailio kamailio
cd kamailio


 make include_modules=”db_mysql” cfg
</code></pre>
<p>如果要安装到自己预想的安装位置处，则</p>
<pre><code>make PREFIX=&#34;/usr/local/kamailio&#34; include_modules=&#34;db_mysql&#34; cfg
</code></pre>
<p>4 . 编译并安装</p>
<pre><code>make all

make install
</code></pre>
<p>如果查看kamailio的目录情况</p>
<pre><code>root@debian440p:/usr/local/src/kamailio/kamailio# kamailio -I
</code></pre>

<p>6 . 创建运行数据库</p>
<p>kamdbctl create</p>
<p>按提示输入mysql root用户密码后，即可创建kamailio运行数据库</p>
<p>7 . 配置 脚本文件kamailio.cfg</p>
<pre><code>#!define WITH_MYSQL
#!define WITH_AUTH
#!define WITH_USRLOCDB

#!define DBURL &#34;mysql://kamailio:kamailiorw@localhost/kamailio&#34;
</code></pre>
<p>8 . 运行kamailio</p>
<pre><code>cp pkg/kamailio/deb/debian/kamailio.init /etc/init.d/kamailio
chmod 755 /etc/init.d/kamailio

cp pkg/kamailio/deb/debian/kamailio.default /etc/default/kamailio


/etc/init.d/kamailio start
/etc/init.d/kamailio stop
</code></pre>
<p>在这里如果启动失败，需要从系统日志中查看问题根源，centos下是/var/log/message,debian下是 /var/log/syslog</p>
<h3>二 、 Siremis安装</h3>
<p>1 . apache2安装</p>
<pre><code>apt-get install apache2
a2enmod rewrite
apt-get install php5 php5-mysql php5-gd php5-curl
</code></pre>
<p>2 . 下载安装 Siremis</p>
<pre><code>cd /var/www
wget http://siremis.asipto.com/pub/downloads/siremis/siremis-4.2.0.tgz
tar xvfz siremis-4.2.0.tgz
cd siremis-4.2.0
make prepare
make chown
</code></pre>
<p>3 . 数据库中给siremis用户赋权限</p>
<pre><code>GRANT ALL PRIVILEGES ON siremis.* TO siremis@localhost IDENTIFIED BY &#39;siremisrw&#39;;
</code></pre>
<p>4 . 生成siremis的apache配置脚本</p>
<pre><code> make apache-conf
</code></pre>
<p>5 . 将生成的siremis脚本添加到/etc/apache2/sites-available/default 中</p>
<p>6 . 重启 apache /etc/init.d/apache2 restart</p>
<p>7 . 访问siremis并最终通过页面完成最后的配置 </p>
<pre><code>http://yourserveraddress/siremis/
