# Kamailio配MediaProxy


		<a href="37.html"><h1>Kamailio配MediaProxy</h1></a>
                <br/><b>                <p>以下由QQ群友 風華血月(963641045)分享</p>
<p>1.环境：阿里云Debian 8.04 64位系统，防火墙默认开启，数据库mysql</p>
<p>防火墙充许所有的请求</p>
<p>2.默认已经安装了kamailio,配置连mysql数据库，添加用户，不会的可以根据官方文档：  http://www.kamailio.org/wiki/install/4.4.x/git</p>
<p>或群里崔工文档进行安装</p>
<p>3.安装mediaproxy，mediaproxy属于AG Projects ，参考官方文档：http://mediaproxy.ag-projects.com/projects/mediaproxy/wiki/InstallationGuide</p>
<p>首先添加AG Projects - Software Repositories ：http://projects.ag-projects.com/projects/documentation/wiki/Repositories</p>
<p>根据我自己系统选择</p>
<p>加入/etc/apt/sources.list。</p>
<p>然后添加key：</p>
<p>wget http://download.ag-projects.com/agp-debian-gpg.key</p>
<p>apt-key add agp-debian-gpg.key （如不是root用户，需要前面加 sudo）</p>
<p>apt-get update</p>
<p>添加AG Projects源完成。</p>
<p>安装mediaproxy命令如下：</p>
<p>apt-get install mediaproxy-dispatcher mediaproxy-relay mediaproxy-web-sessions</p>
<p>4.配置mediaproxy，mediaproxy依赖IPtables（默认开启）</p>
<p>开启ip_forward</p>
<p>sed -i &#39;s#net.ipv4.ip_forward = 0#net.ipv4.ip_forward = 1#g&#39; /etc/sysctl.conf</p>
<p>sysctl -p</p>
<p>打开/etc/mediaproxy/config.ini ,修改如下：
dispatchers = 192.168.88.245（你可以改为自己机器公网IP）
passport = None
relay_ip = 192.168.88.245（你可以改为自己机器公网IP）
port_range = 50000:60000
log_level = DEBUG
on_hold_timeout = 1800
[Dispatcher]
socket_path = dispatcher.sock
listen = 192.168.88.245（你可以改为自己机器公网IP）
listen_management = 192.168.88.245（你可以改为自己机器公网IP）
management_use_tls = no
passport = None
management_passport = None
log_level = DEBUG
[TLS]
[Database]
[Radius]
[kamailio]     （我们用的kamailio，把OpenSIPS改为kamailio）
socket_path = /var/run/kamailio/socket
max_connections = 10</p>
<p>5.kamailio配置mediaproxy</p>
<p>在kamailio的配置文件kamailio.cfg的route上面增加</p>
<p>loadmodule &#34;mediaproxy.so&#34;
modparam(&#34;mediaproxy&#34;, &#34;disable&#34;, 0)
modparam(&#34;mediaproxy&#34;, &#34;mediaproxy_socket&#34;, &#34;/var/run/mediaproxy/dispatcher.sock&#34;)
modparam(&#34;mediaproxy&#34;, &#34;mediaproxy_timeout&#34;, 1000)
modparam(&#34;mediaproxy&#34;, &#34;signaling_ip_avp&#34;, &#34;$avp(nat_ip)&#34;)
modparam(&#34;mediaproxy&#34;, &#34;media_relay_avp&#34;, &#34;$avp(media_relay)&#34;)
modparam(&#34;mediaproxy&#34;, &#34;ice_candidate&#34;, &#34;low-priority&#34;)</p>
<p>Ps:这没有验证，仅供参考，参考链接：http://fengwan.blog.51cto.com/508652/1652807
问题：</p>
<p>运行media-dispatcher可能没有问题，可是运行media-relay可能会出现问题</p>
<p>运行命令：lsmod | grep nat 没有输出</p>
<p>解决方法：</p>
<p>运行命令： modprobe iptable_nat</p>
<p>在运行：lsmod | grep nat</p>
<p>使用modprobe iptable_nat可能重新启动后就失效，这个时候你需要</p>
<p>echo &#34;modprobe iptable_nat&#34; &gt;&gt; /etc/sysconfig/modules/iptable_nat.modules</p>
<p>chmod +x /etc/sysconfig/modules/iptable_nat.modules</p>
<p>在启动media-relay就成功了。</p> <br/><hr/>如果在有疑问或需要沟通的地方，可以QQ：1354608370 或 加FreeSWITCH+Kamailio+Opensips QQ群： 293697898 沟通交流！
