# SIP录音系统带质检（语音识别存文本）正式上线


		<a href="43.html"><h1>SIP录音系统带质检（语音识别存文本）正式上线</h1></a>
                <br/><b>                <p>V1.0</p>
<p>说明
软件是用于针对其它第三方的sip服务因种种原因不进行录音，从而使用我们的录音系统进行录音，支持G711,G729，G723等录为WAV,从而避免该进行管理的录音没有。</p>
<p>使用端口镜像或者SIP服务器的同机安装使用。端口镜像需要把SIP信令和RTP数据转向安装录音系统的IP。</p>
<p>在录音结束后，由系统自动向第三方的识别系统发起ASR识别，支持讯飞，阿里，捷通华声等第三方识别系统。</p>
<p>配置文件</p>
<p>vi /opt/recordd/config.cfg</p>
<pre><code>[SET]

#ali,baidu,xf,jthsh

ENGINE=xf

ASRSERVERIP=https://xxxx.xx.x/xxxx

APPKEY=dfslkfdlsj99

APPID=klsjkdfjsd



LOG_DIR=7

LOG_CACHE=1

LOG_LEN=1500

TEST_MODE=0

SIP_TIMEOUT=120

WORK_THREAD=100

SIP_NETCARDNO=eth0

SIP_HOST=192.168.1.203

SIP_PORT=5060

SIP_FILTER=udp and host 192.168.1.203 and port 5060

RTP_NETCARDNO=eth0

RTP_FILTER=udp and host 192.168.1.203

DBSTR = &#34;user=postgres dbname=records password=Nway2017 host=127.0.0.1 port=5432 sslmode=disable&#34;
</code></pre>
<p>以上的192.168.1.203为我们的SIP信令或RTP媒体包经过的服务器或IPPBX等的IP地址</p>
<p>接着，就可以重启了，就可以用了</p>
<p>Web管理界面为 : http://ip:9080/index admin admin</p>
<p>系统默认的用户名和密码为: root ,Nway123</p>
<p>然后就可以通过web页面看到录音了</p>
<p>服务名称</p>
<p>/etc/init.d/recordserver 为录音服务</p>
<p>/etc/init.d/recordweb 为录音服务的web查看</p>
