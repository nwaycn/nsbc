# Opensips脚本操作


		<a href="6.html"><h1>Opensips脚本操作</h1></a>
                <br/><b>                <p>Assignments, string and arithmetic operations can be done directly in the configuration file.</p>
<p>1 . Assignment</p>
<pre><code>Assignments can be done like in C, via &#39;=&#39; (equal) operator. Not that not all variables (from script) can be written, some are read-only. Check with listing of variables to see which ones can be written too.
$var(a) = 123;
$ru = &#34;sip:user@domain&#34;;
There is a special assign operator &#39;:=&#39; (colon equal) that can be used with AVPs. If the right value is null, all AVPs with that name are deleted. If different, the new value will overwrite any existing values for the AVPs with than name (on other words, delete existing AVPs with same name, add a new one with the right side value).
$avp(val) := 123;
</code></pre>
<p>2 . String operations</p>
<pre><code>For strings, &#39;+&#39; is available to concatenate.
$var(a) = &#34;test&#34;;
$var(b) = &#34;sip:&#34; + $var(a) + &#34;@&#34; + $fd;
</code></pre>
<p>3 . Arithmetic and bitwise operations</p>
<pre><code>For numbers, one can use:
+ : plus
- : minus
/ : divide
* : multiply
% : modulo
| : bitwise OR
&amp; : bitwise AND
^ : bitwise XOR
~ : bitwise NOT
&lt;&lt; : bitwise left shift
&gt;&gt; : bitwise right shift
Example:
$var(a) = 4 + ( 7 &amp; ( ~2 ) );
NOTE: to ensure the priority of operands in expression evaluations do use __parenthesis__.
Arithmetic expressions can be used in condition expressions via test operator &#39; [ ... ] &#39;.
if( [ $var(a) &amp; 4 ] )
    log(&#34;var a has third bit set\n&#34;);
