关于 NSBC

一体化 SIP 全栈平台：把 SBC 安全、PBX 功能与 SIP 代理性能收敛进一个守护进程。

我们的思路

把边界做薄，把可控性做实

NSBC 不基于 PJSIP、Sofia-SIP 或 reSIProcate：解析器、事务状态机与 B2BUA 环路全部用 C11 从零实现， 因此每个行为都可审计、可预测。管理面用 Rust 承担数据库与 Web API，C 核心保持零运行时数据库依赖。

我们选择开源，是因为 SIP 互通的复杂性只能在真实环境中打磨。你在部署中遇到的问题， 往往就是下一版要修的地方。

NSBC 由上海宁卫信息技术有限公司维护，基于 Apache License 2.0 发布。

工程取向

标准化协议优先，配置显式化，日志可检索，失败路径可复现。

交付方式

源码开放，可自行构建与私有化部署；企业场景可提供部署支持与定制开发。

技术栈

C11 数据面 + Rust 管理面，OpenSSL / libsrtp2 / libpcre2，Linux x86_64。

About NSBC

An all-in-one SIP full-stack platform: SBC security, PBX features and SIP proxy performance — consolidated into a single daemon.

Our approach

Keep the boundary thin, make control solid

NSBC is not built on PJSIP, Sofia-SIP or reSIProcate: the parser, transaction state machine and B2BUA loop are all implemented from scratch in C11, so every behavior is auditable and predictable. The management plane uses Rust for the database and web API, while the C core keeps zero runtime database dependency.

We chose open source because the complexity of SIP interoperability can only be polished in real-world environments. The issue you hit during deployment is likely exactly what needs fixing in the next release.

NSBC is maintained by Shanghai Ningwei Information Technology Co., Ltd. and released under the Apache License 2.0.

Engineering values

Standards-first, explicit configuration, searchable logs, reproducible failure paths.

Delivery model

Source-available, build it yourself or deploy privately; enterprise scenarios can get deployment support and custom development.

Stack

C11 data plane + Rust management plane, OpenSSL / libsrtp2 / libpcre2, Linux x86_64.
